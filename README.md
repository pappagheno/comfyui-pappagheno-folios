# 📜 FOLIOS (comfyui-pappagheno-folios)

A custom prompt management and lazy-loading picker node for ComfyUI, featuring a custom ancient papyrus LiteGraph canvas interface.

## ✨ Key Features
- **True Lazy Evaluation**: Evaluates only the active prompt branch, saving compute and VRAM during heavy testing pipelines.
- **Dynamic Slot Management**: Automatically manages input connections while preserving fixed prompt indexing for stable shot referencing.
- **Bespoke Canvas Aesthetic**: Custom LiteGraph canvas rendering featuring dynamic hieroglyphic scroll borders and an aged parchment text preview widget.

## 📦 Installation

Navigate to your ComfyUI `custom_nodes` directory:

```bash
cd ComfyUI/custom_nodes
git clone [https://github.com/pappagheno/comfyui-pappagheno-folios.git](https://github.com/pappagheno/comfyui-pappagheno-folios.git)
